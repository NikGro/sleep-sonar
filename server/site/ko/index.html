소리로 보는 잠

밤이면 Suya가 곁에서 귀를 기울입니다. 호흡과 움직임, 소리로 수면 단계를 추정하고, 얕은 잠에서 부드럽게 깨우며, 밤을 Apple 건강 앱에 기록합니다. 손목에 시계가 없어도 됩니다.

나의 밤은 내 iPhone에 남습니다. 계정도 광고도 추적도 없습니다. 명시적으로 선택한 경우에만, 모두를 위해 Suya를 더 정확하게 만들도록 밤의 대략적인 소리 그림(소리 없음)을 기증합니다.

Suya는 의료기기가 아닙니다.
