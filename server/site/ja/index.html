音から眠りを知る

夜、Suyaはあなたのそばで耳を澄ませます。呼吸や体の動き、物音から睡眠段階を推定し、浅い眠りのときにやさしく起こし、夜のデータをAppleヘルスケアに記録します。手首に時計は不要です。

あなたの夜はあなたのiPhoneに残ります。 アカウントも広告もトラッキングもありません。あなたが明示的に選んだ場合にだけ、みんなのためにSuyaをより正確にするため、夜のおおまかな音の画像（音声なし）を寄付します。

Suyaは医療機器ではありません。
